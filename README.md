## 🚀 Featured Projects

### 🌿 Eden — AI-Powered Misinformation Analysis Engine
> *Cold Intelligence // Forensic Media Fact-Checking Terminal*

Unmasking misinformation through multi-modal AI orchestration. Eden ingests social media content (Instagram Reels, images, video uploads), decomposes it into frames, audio, and text, then applies state-of-the-art AI reasoning to identify and verify factual claims against live authoritative sources.

**Key Highlights:**
- Multi-modal pipeline: **EasyOCR** (vision) + **OpenAI Whisper** (audio) + **Gemini 2.0 Flash** (reasoning)
- Asynchronous task chaining via **Celery + Redis** with fallback orchestration
- Dual-path degraded mode prevents pipeline failures during API quota limits
- Cyberpunk forensic terminal UI with threat index gauge, ⌘K command palette, and PDF dossier export
- Fully containerized with **Docker Compose**

`Python` `Django` `React 18` `Celery` `Redis` `Gemini` `Whisper` `EasyOCR` `FFmpeg` `yt-dlp` `Docker` `PostgreSQL`

### 🛒 Zemo — AI-Powered E-Commerce Intelligence Platform
> *The next-generation autonomous price tracking and sentiment analysis engine.*

Zemo transforms raw product data into actionable purchasing insights. Traditional price trackers show numbers — Zemo explains the *why* using LLM-driven semantic analysis of thousands of customer reviews.

**Key Highlights:**
- Headless browser orchestration via **Playwright** for real-time price scraping
- **Meta Llama 3 8B** semantic analysis extracting structured pros/cons from 100+ reviews
- Price history visualized with **Plotly.js** charts, tracked with millisecond precision
- Real-time **Firebase** threshold alerts when products hit target prices or historic lows
- Industrial-grade **cron-based polling engine** with fault-tolerant retry logic

`Node.js` `Express` `MongoDB` `Playwright` `Llama 3` `HuggingFace` `Firebase` `React 18` `Plotly.js` `Tailwind CSS`
